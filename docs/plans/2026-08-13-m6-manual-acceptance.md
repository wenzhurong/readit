# M6 macOS 真机手工验收清单

**日期**：2026-08-13  
**产品下限**：macOS 14 + Safari ≥ 17.2  
**状态规则**：只有在符合产品下限的真实 macOS 安装包上完成操作后才能勾选。未勾选表示
验收未达成；Playwright WebKit、Rust 单元测试或恒跳过测试都不能替代这里的结果。

## 1. 双击 Markdown 文件

- [ ] **操作**：退出 readit；在 Finder 中分别双击一个 `.md` 和一个 `.markdown` 文件，
  两个文件均包含相对图片及一个指向同目录另一 Markdown 文件的链接。
  **期望**：readit 启动并显示被双击文件；相对图片可见；标题/内容与磁盘一致；两种扩展名
  均由同一个应用关联，窗口不出现空白文档。

## 2. 第二次启动路由到既有窗口

- [ ] **操作**：保持 readit 已打开文档 A；从 Finder 双击文档 B，随后再从终端以带文档 C
  参数的方式启动 readit。
  **期望**：系统中始终只有一个 readit 应用实例；既有窗口被显示并聚焦，B、C 依次进入
  该窗口的文档导航历史；后退/前进可回到 A、B、C 的正确内容。

## 3. Cmd+F

- [ ] **操作**：打开含多个相同词、且至少一个命中位于首屏之外的文档；按 `Cmd+F`，输入
  查询词，使用 Enter、Shift+Enter 和界面前后按钮，再按 Escape。
  **期望**：组件自带查找栏获得焦点；总数/当前序号正确；当前命中滚入视野；正向与反向
  循环一致；Escape 关闭查找栏且文档 DOM/内容未被破坏。

## 4. 原子保存文件监听

- [ ] **操作**：readit 打开文档后，用会采用“临时文件 + rename”方式保存的编辑器修改并
  保存该文档；再用普通原地写入方式保存一次。
  **期望**：两种保存方式都只触发有效刷新，readit 显示最新完整内容；不丢失监听、不读到
  半写入文件、不进入重复刷新循环。

## 5. 真 WKWebView Mermaid

- [ ] **操作**：在符合产品下限、Safari 恰为 17.2 的可用测试机上打开 Mermaid 样例，覆盖
  flowchart、长标签、HTML label、`classDef`/`style` 中的 opacity/transform/filter 以及语法
  错误；若没有该版本测试机，记录实际系统与 Safari 版本且保持本项未勾选。
  **期望**：合法图在 WKWebView 中可见，标签不丢失且无明显错位；危险图层属性被护栏移除；
  语法错误保留 Phase A 源码并显示错误态。若 17.2 失败，记录首个通过版本并上调发布下限。

## 6. 安装体积、冷启动与稳态内存

- [ ] **操作**：用 release 配置生成并安装 `.app`/`.dmg`；记录安装包与展开后应用体积；重启
  系统或确保进程/缓存条件可说明后测至少 5 次冷启动；打开一份普通、无数学/高亮/Mermaid
  的文档，静置 60 秒后记录稳态常驻内存，另行记录四个大件同时渲染的压力场景。
  **期望**：报告分别列出体积、每次冷启动及中位数、普通文档稳态内存、压力场景内存；不得
  用既有 514 MB 压力读数冒充稳态，也不得在尚无预算裁决时自行宣称性能通过。
